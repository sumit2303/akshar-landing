# Akshar Web Landing & Privacy Policy

Official static landing page and COPPA-compliant privacy policy for **Akshar** — Augmented Reality early childhood education.

* **Live Domain**: [https://aksh.ar](https://aksh.ar)
* **Hosting**: GitHub Pages with automatic TLS/HTTPS
* **Custom Domain**: Configured via `CNAME` (`aksh.ar`)

## Structure
* `index.html`: Responsive Candy Glass landing page with live AR interactive previews, curriculum overview, and store links.
* `privacy-policy.html`: COPPA & Apple/Google Play Kids Category certified privacy policy.
* `CNAME`: Custom domain apex pointer (`aksh.ar`).
